# Decisions — P015 設計決策

已在開發中確立、之後修改應維持的做法。來源標示：〔碼〕＝倉庫 index.html 可見；〔記〕＝Claude 專案開發紀錄。

1. **畫布座標與實體燈號分離**〔碼〕〔記〕
   繪圖、圖章、文字一律在畫布座標（左上原點）進行；只在輸出時轉成燈號。走線方式（起點角落、垂直／水平、S 型或 Z 型）造成的倒置、鏡像錯誤，過去多次出現在把兩套座標混用的地方。

2. **浮動預覽再套用**〔記〕
   文字與圖章先以浮動層顯示，可拖曳、縮放、微調；Enter 才寫入影格，Esc 放棄。避免一次放置就污染影格、也讓復原紀錄乾淨。

3. **新增影格＝空白，複製影格＝帶內容**〔碼〕〔記〕
   兩種意圖分成不同函式，曾因共用路徑導致新增影格預先帶入畫面。

4. **大量燈珠分段多腳位輸出**〔碼〕〔記〕
   燈數大時把燈串分給多支資料腳位並行更新以降低延遲（576 顆用 Pin 9／Pin 10 各 288 顆）。index.html 的「分段控制」可設定段數與腳位。

5. **字型掃描 CJK 優先**〔記〕
   Python 版文字工具列出本機字型時，把支援中日韓字元的字型排在前面。

6. **單檔交付**〔碼〕
   網頁維持單一 HTML 檔，方便 EZPage／GitHub Pages 直接部署與現場離線開啟。
