# Protocol — P015 WebSerial 影格格式

依 index.html `buildFrameData()`（約第 10323 行）整理。傳送前先把畫布順序經 `canvasToLedIndex()` 轉成實體燈號順序；每次送出一整個影格。

| 格式 | 內容 | 說明 |
| --- | --- | --- |
| 二進制（預設、最快） | `0xFF` `N低位` `N高位` 後接 N 組 `R G B` 位元組 | N＝LED 數量，無校驗和 |
| 十六進制文字 | `F:RRGGBB,RRGGBB,...\n` | 大寫十六進位，逗號分隔 |
| RGB 文字（最慢、最穩） | `R,G,B;R,G,B;...\n` | 十進位，分號分隔 |

- 鮑率選項：9600～921600，預設 115200。
- 清除、紅／綠／藍／白、漸層等測試都是送一整個影格；逐顆測試最多 100 顆，間隔取「傳送延遲」設定加 30 ms。
- 對應的 Arduino 接收端程式由「接收端程式」功能（`generateReceiverCode()`，約第 10574 行）依目前設定產生；修改格式時兩邊要同時改。
